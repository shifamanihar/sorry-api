# 💕 sorry-baby

A tiny Node.js package that generates cute random apology messages with adorable kaomoji.

Because sometimes saying "sorry" needs a little extra cuteness. 🥺👉👈❤️

## 📦 Installation

```bash
npm install sorry-baby

🚀 Usage
const sorry = require("sorry-baby");

console.log(sorry("Baby"));

You can also use it without passing a name:
const sorry = require("sorry-baby");

console.log(sorry());

💌 Example Output
🥺 I'm really sorry, Baby... Please don't be angry with me 👉👈 ❤️

(づ｡◕‿‿◕｡)づ ❤️

Every time you call sorry(), it randomly selects a cute apology message and kaomoji. 🥹
